# Student Management System

## About the Project

Student Management System is a web-based application developed using Python, Flask and MySQL.

The system helps to manage student records, attendance/absence records and fine details.

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS

## Features

- Add Student
- View Student Records
- Edit Student Details
- Delete Student
- Search Student
- Record Student Absence
- Manage Fine Details
- Student Dashboard
